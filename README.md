# Pigg Party Growth Audit

**Live → https://eddieatadapty.github.io/pigg-party-flow-rebuild/**

Five ideas to turn more Pigg Party users into subscribers, each built into a clickable version of Pigg Party's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Keep the ad’s free first pull inside the first session | +10–20% CR to first purchase |
| 02 | Dress their pigg in the answer they gave | +5–15% CR to first purchase |
| 03 | Three packs, not seven, in the first shop | +5–10% CR to first purchase |
| 04 | Catch the people who close the shop | +3–8% ARPU |
| 05 | Proof next to the first paid pull | +2–5% CR to first purchase |

Every price, rating and feature comes from Pigg Party's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ apps, not measured lift for Pigg Party. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
